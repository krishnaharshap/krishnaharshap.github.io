# krishnaharshap.github.io

Personal QA / test automation portfolio, live at [krishnaharshap.github.io](https://krishnaharshap.github.io/).

Static site (`index.html` + `style.css`), no build step, deployed via GitHub Pages.

## Structure

- `index.html`: page content
- `style.css`: styling
- `.nojekyll`: disables Jekyll processing so the site is served as-is
